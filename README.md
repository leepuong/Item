# Font display tool

Hi there! This is a tool that helps you get a more visual understanding when choosing fonts without having to install them on your personal computer.

> Disclaimer: These wallpapers are sourced from various internet sources. I am not the creator of any of these wallpapers. If you are the author of any of these wallpapers, please [**contact me**](https://github.com/leepuong), and I will gladly remove the wallpaper or add author information to this README.
